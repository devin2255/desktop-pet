# Duo 帐篷待机（StandBy）设计

日期：2026-09-14  
分支：`feature/son-mode`  
状态：已实现，待真机确认帐篷外观  
前置：`docs/superpowers/specs/2026-09-11-brother-duo-design.md`  
本规格只做半折帐篷，不做价格雷达、分屏缝合、拖到一半吸附进帐篷。

## 目标

给带 `duo` 的资源包增加一种 **单窗半开** 待机：合上的双人窗立成帐篷，朝外一页是带秒的时钟。对标 iPhone Duo 半折 StandBy（「立在桌上的钟」），不把苹果商标或官方 UI 画进帧里。

播放器只增加通用 `tent` 能力；文案、是否启用全部来自 `pet.json` 的 `duo.tent`。没有该字段的包行为不变。

## 决策摘要

| 项 | 决策 |
|---|---|
| 形态 | 方案 A：始终一个窗口，过渡层停在约一半，两页撑成帐篷 |
| 进入 | 仅合上态右键「支起来」；不把开合拖到中段做成进帐篷 |
| 离开 | 「收起来」→ `folded`；「展开」→ 现有满进度展开到 `open` |
| 展开态 | 不能直接支帐篷，须先合上 |
| 时钟 | 外屏 `HH:mm:ss`，带日期；每秒刷新 |
| 画饼 | 帐篷内完全不听：不匹配关键词、不说话、不播雷达音频 |
| 盯盘 | 帐篷外屏只显示钟，不叠行情；头上 ticker 一并隐藏，离开帐篷再恢复 |
| 人物 | 用根级坐下/待机，不新画角色条 |
| 互动 | 左键整窗拖走；不散步、不爬窗/坐窗/吊挂/坠落 |

## 状态机

在现有四态上增加互斥状态 `tent`：

| 状态 | 窗口 | 行为 |
|---|---|---|
| `folded` | 1 | 与现在相同 |
| `tent` | 1（同一窗） | 半开壳 + 外屏钟；停漫游；停窗口边互动；停画饼；停盯盘展示 |
| `unfolding` / `open` / `folding` | 与现在相同 | 与现在相同 |

允许的转换：

- `folded` → `tent`（菜单 `duo-tent`）
- `tent` → `folded`（菜单 `duo-untent`）
- `tent` → `unfolding` → `open`（菜单 `duo-unfold`，走现有满进度展开）
- `folded` ⇄ `open` 手势与菜单保持现状
- 禁止：`open` → `tent`；禁止手势停在半开当帐篷

中断（托盘隐藏、左键拖开始、切宠物、退出）：

- 若当时是 `tent`：取消其它过渡后 **保持 `tent`**（它是稳态，不是过渡）
- `unfolding` / `folding` 仍弹回进入前状态；进入前若是 `tent`，弹回 `tent`

隐藏再显示：回到隐藏前的 `folded` / `tent` / `open`。

## 菜单

合上态（`folded`）在已有项之外增加：

- `{ id: 'duo-tent', label: '支起来' }`  
  无 `action`/`sequence` 动画义务；主进程识别 id 后切 `tent`。播放根级 `duo.tent.action`（缺省 `sit`，没有则 `idle`）。

帐篷态（`tent`）菜单替换为短菜单（最多 8 项，本规格用 3 项）：

- `{ id: 'duo-untent', label: '收起来' }` → `folded`，播回 `idle`
- `{ id: 'duo-unfold', label: '展开' }` → 现有满进度展开
- 可保留一项轻互动（如「睡会儿」），**不得**出现画饼雷达开关或会触发 `watch` 的项

展开态菜单不变，不含「支起来」。

右键位移规则不变：短按出菜单，水平拖仍只在 `folded`/`open` 之间开合，`tent` 下水平拖不当开合（避免误展开），松手出菜单。

## 视觉

- 复用现有 `.duo-overlay` / `.duo-device`，`--duo-open` 固定在 **0.48**（两页明显撑开，仍是一座帐篷，不是全开书）
- 设备绕底边轻微立起（CSS 即可），落在当前窗底边，不另开 BrowserWindow
- **外页（朝用户）**：大号 `HH:mm:ss`（本地时区，24 小时制）+ 一行日期（如 `9月14日 周一`）；每秒对齐系统时钟更新
- **内页**：半透明，能看见根级双人坐/待机，人不被钟挡住脸
- 禁止苹果 Logo、灵动岛仿品、官方文案「Hello, hello」
- 不新做角色 PNG；壳与钟全是渲染层

窗尺寸：沿用合上 `currentSize()`，不换成成员窗。脚底与合上态对齐，支起来时窗可略增高以容纳立起的壳，加高部分只往上长，脚底不动。

## 画饼与盯盘

帐篷是「不办公」的钟。

- 进入 `tent`：暂停消息/关键词监听（与托盘隐藏同等静音），清空待播画饼队列，不说话
- 停留期间：不匹配「上市 / 功劳 / 画饼 / 带你看比特币」等任何 `watch` 规则
- 离开 `tent`：按现有逻辑恢复监听（仅当用户本来开着雷达且当前视图允许）
- 帐篷外屏 **不** 显示大盘 ticker；`.ticker` 隐藏

## 行为细节

- 进入时 `pauseBehavior()`，不 `scheduleBehavior`
- `interaction` 视为非 `normal` 或显式 suspend：不吸附窗口边
- 左键拖：整窗移动，松手停在当前位置（与合上拖窗相同），不弹回屏幕底
- 透明像素仍鼠标穿透；钟与壳的不透明区域可点出菜单、可拖
- 合上「支起来」时若正在走/爬：先停步再立帐篷

## `pet.json`

`schemaVersion` 仍为 `1`。`duo.tent` 可选：

```json
{
  "tent": {
    "action": "sit",
    "enterLabel": "支起来",
    "leaveLabel": "收起来",
    "openProgress": 0.48
  }
}
```

校验：

- 有 `duo` 才允许 `duo.tent`
- `action` 若出现必须是根级已有动画名
- `enterLabel` / `leaveLabel`：1～24 字
- `openProgress`：0.35～0.65，缺省 0.48
- 无 `duo.tent`：不出现「支起来」，控制器没有 `tent` 态

兄弟 Duo 打开 `duo.tent`，`action` 用根级 `sit`。

## 播放器改动面

| 模块 | 职责 |
|---|---|
| `duo-controller.js` | 增加 `tent` 稳态；`beginTent` / `leaveTent`；`mode()==='tent'` 时 `beginUnfold` 仅允许菜单驱动的满行程 |
| `main-v3.js` | 菜单 id 分发；进帐篷停漫游/互动/雷达；出帐篷恢复；不创建第二窗 |
| `renderer-v3.js` + CSS | 帐篷姿态、外屏钟（含秒）、隐藏 ticker |
| `market-watch` / `message-watcher` | 主进程在 `tent` 时不向该窗推命中 |
| `petpack-validator.js` | 校验可选 `duo.tent` |
| 单测 | 进/出帐篷、帐篷内不许手势开合、无 tent 字段的包不出现该态 |

不为 `brother-duo` 写死角色名。

## 失败回退

| 情况 | 行为 |
|---|---|
| 包无 `duo.tent` | 无入口，状态机到不了 `tent` |
| `tent.action` 缺帧 | 退回 `idle`，仍立帐篷和钟 |
| 过渡层失败 | 仍切 `tent`：停漫游 + 显示钟，壳可以不立起 |
| 开合中途点「支起来」 | 忽略，先结束或取消过渡 |

## 质量门禁

- 合上右键能支起来；帐篷外屏每秒跳秒，日期正确
- 帐篷内发「上市/画饼」类群消息 **不得** 出声、不得播雷达
- 帐篷内不出现爬窗/坐窗/坠落，不自动散步
- 「收起来」回到合上双人漫游；「展开」仍原地拆成两人
- 托盘隐藏/显示保持 `tent`
- 无 `duo.tent` 的包（如仅有 duo 的夹具）回归测不破
- 语法检查 + `test-duo-controller` + 兄弟 Duo petpack 测；再打客户 EXE 手测

## 首版不做

- 拖到一半松手进帐篷
- 从展开态直接对撑成帐篷
- 第二窗口、真双屏
- 外屏天气、相册、多个小组件
- 价格/黄牛倒计时台词
- 数字签名

## 建议实现顺序

1. `duo-controller`：`tent` 进出 + 单测  
2. 主进程菜单与三停（漫游、边互动、画饼）  
3. 渲染：半开壳 + `HH:mm:ss` 钟  
4. 兄弟 Duo 清单补 `duo.tent`，校验、打包、启动手测
