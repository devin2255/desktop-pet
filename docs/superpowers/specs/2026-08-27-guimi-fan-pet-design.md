# 粉丝闺蜜桌宠设计（闺蜜桌宠）

日期：2026-08-27  
分支：`feature/bestie-pets-design`  
状态：已确认，待写实现计划  
关联：复用 `2026-08-04-bestie-pets-design.md` 的一体双人与序列能力；跪爬模式对齐 `feature/son-mode` 兄弟桌宠通用实现

## 目标

用粉丝提供的两位闺蜜照片，制作一体双人桌面宠物「闺蜜桌宠」：单窗口始终同框，含闺蜜彩蛋、投喂臭粑粑、叫爸/下跪、跪爬模式与「去放松」剧情。交付客户可直接双击的 Windows 便携版 EXE，不要求安装开发环境或手动导入资源包。

## 决策摘要

| 项 | 决策 |
|---|---|
| 呈现形态 | 一体双人：单窗口、单 petpack，两人始终同框 |
| 宠物名 / 程序名 | 闺蜜桌宠 |
| package id / delivery-id | `guimi` |
| 角色命名 | 不单独起名；气泡台词不分角色，两人一起说 |
| 站位 | 左：闺蜜一；右：闺蜜二；全动作禁止左右互换 |
| 画风 | 偏真人，小尺寸仍可辨认两人 |
| 日常服装 | 全部日常动作（含跪爬）固定用散步穿搭 |
| 合影服装 | 触发拍照/合影时变装 |
| 去放松服装 | 剧情换装段使用指定两套 |
| 投喂 | 保留投喂菜单；物品全部改为臭粑粑 |
| 去放松点击 | 男模登场后**不停**，直接进入拥抱及后续 |
| 跪爬 | 右键勾选「跪爬模式」，行为对齐兄弟桌宠 |
| 资源策略 | 新建独立 `guimi` 包，不覆盖 `xiaomei-xiaotian` |
| 播放器 | 从兄弟桌宠分支接入通用跪爬模式；不写死角色名 |

## 架构

### 资源侧

- 输出：`pets/packages/guimi.petpack`
- 解包库：`pets/library/guimi/`
- 工作目录：`pets/work/guimi/`
- 人设、台词、菜单、序列、跪爬所需动画全部进 `pet.json`，播放器不写死「闺蜜」

### 播放器侧（通用能力）

本分支若尚未具备跪爬模式，从 `feature/son-mode` 接入通用能力（不引入角色分支）：

1. 设置项 `crawlMode`（默认 `false`）
2. 托盘/右键勾选「跪爬模式」；仅当 `animations.crawl` 存在时显示
3. `crawlMode` 开启且「在桌面散步」开启时，漫游移动用 `crawl-left` / `crawl-right`，不用直立 `walk`
4. `crawlMode` 开启时：待机为爬姿（`crawl-left` / `crawl-right` 保持朝向）；日常随机不再站立坐睡，只在爬姿下挪动
5. 「下跪」在爬行模式且存在 `kowtow-crawl` 时，改播 `kowtow-crawl`
6. 渲染侧识别 `crawl-left` / `crawl-right` 并镜像

客户构建：

```powershell
npm run build:customer -- --pet pets/packages/guimi.petpack --name "闺蜜桌宠" --delivery-id guimi
```

客户版默认隐藏导入、切换宠物、打开宠物库。

## 服装与动作映射

| 场合 | 服装 | 覆盖动作 |
|---|---|---|
| 日常 | 散步穿搭 | `idle` `walk` `sit` `sleep` `reaction` `cuddle` `whisper` `cheer` `drag` 及窗口边缘相关日常帧；`crawl` / `kowtow` / `kowtow-crawl` / `call-dad` |
| 合影 | 合影变装 | `selfie`（及 selfie 序列各阶段） |

## 动画清单

### 标准动作（日常装，双人同框）

| 动作 | 帧数 | 画面 |
|---|---|---|
| `idle` | ≥4 | 并肩轻晃、偶尔对视眨眼 |
| `walk` | ≥6 | 并排右向直立走；向左由播放器镜像 |
| `sit` | ≥4 | 并排坐 |
| `sleep` | ≥4 | 并排小憩 |
| `reaction` | ≥4 | 点击惊喜；闺蜜二可轻比耶 |

### 跪爬 / 叫爸 / 下跪（日常装）

| 动作 | 触发 | 画面 / 台词 |
|---|---|---|
| `crawl` | 「跪爬模式」+「在桌面散步」移动；爬姿待机 | 两人并排四肢着地往右爬，≥6 帧；向左镜像 |
| `call-dad` | 菜单「叫爸」 | 两人一起招手喊；气泡「爸！」 |
| `kowtow` | 菜单「下跪」（非爬行模式） | 两人一起跪下磕头；气泡「跪下了」 |
| `kowtow-crawl` | 菜单「下跪」（跪爬模式开启时） | 爬姿版磕头；同台词 |

### 闺蜜彩蛋

| 动作 | 触发 | 服装 | 画面 |
|---|---|---|---|
| `cuddle` | 菜单「贴贴」+ 低权重随机 | 日常 | 靠肩贴贴 |
| `selfie` | 菜单「合个影」序列 | 合影装 | 合影拌嘴后一起拍 |
| `whisper` | 菜单「说悄悄话」+ 偶尔随机 | 日常 | 耳语后偷笑 |
| `cheer` | 菜单「加油鸭」 | 日常 | 并排打气 |
| `drag` | 窗口拖拽 | 日常 | 两人被拖着走 |

合影序列 `selfie-banter` 可沿用现有三段气泡结构，文案改为不分角色的闺蜜口吻。

### 投喂（臭粑粑）

菜单「投喂」使用 `randomActions`，选项全部为臭粑粑相关序列（可 2～3 个变体共用同一物品主题，避免再出现口红/包/裙子）：

| 阶段 | 内容 | 示例台词 |
|---|---|---|
| 1 丢出 | 臭粑粑飞入画面 | 这是什么味儿… |
| 2 反应 | 两人嫌弃 / 惊讶 / 捂鼻 | 臭粑粑！？ |
| 3 收束 | 回日常 `idle` | — |

序列 id 建议：`feed-poop`（若需随机多个动画变体，可用 `feed-poop-a` / `feed-poop-b` 等，物品主题不变）。

### 去放松剧情（`relax`）

菜单「去放松」启动。男模登场后**不设** `waitForClick`，自动进入后续。

| 阶段 | 内容 | 等待点击 | 台词示例 |
|---|---|---|---|
| 1 化妆 | 并肩补妆整理 | 否 | 先弄好看一点～ |
| 2 换装 | 切到去放松两套穿搭 | 否 | 这样…会不会太亮眼 |
| 3 出门 | 并排前往 | 否 | 走！去放松！ |
| 4 男模登场 | 两位男模就位 | **否** | 我要这个 / 我要这个（可双气泡） |
| 5 拥抱 | 各抱一侧 | 否 | — |
| 6 娇羞 | 娇羞互动 | 否 | 好害羞… / 嘿嘿… |
| 7 收束 | 回日常装 `idle` | 否 | — |

中断：拖拽、另选菜单、藏窗 → 中断序列 → 日常 `idle`。

## 行为权重与菜单

### `behavior.random`（日常，非跪爬模式）

| 状态 | 权重 | 示例台词 |
|---|---|---|
| walk | 32 | — |
| sit | 24 | 歇一会儿嘛～ |
| reaction | 16 | 诶嘿！ |
| sleep | 12 | 眯一下… |
| cuddle | 10 | 再靠近一点点 |
| whisper | 6 | 嘘——跟你说哦 |

`selfie`、`cheer`、`relax`、`call-dad`、`kowtow`、投喂 **不进入**随机池。

跪爬模式开启时：播放器强制只调度爬姿移动（与兄弟桌宠一致），忽略上表站立行为。

### 右键自定义菜单（`contextMenuActions`）

| id | 标签 | 行为 |
|---|---|---|
| cuddle | 贴贴 | `cuddle` |
| selfie | 合个影 | `selfie-banter` 序列 |
| whisper | 说悄悄话 | `whisper` |
| cheer | 加油鸭 | `cheer` |
| relax | 去放松 | `relax` 序列 |
| nap | 去睡觉 | `sleep` |
| feed | 投喂 | `randomActions` → 臭粑粑序列 |
| call-dad | 叫爸 | `call-dad`，message「爸！」 |
| kowtow | 下跪 | `kowtow`（爬行模式自动切 `kowtow-crawl`） |

若当前校验上限为 8，制作时将通用 `contextMenuActions` 上限提升到 **12**（仍不写死角色）。

### 播放器系统勾选项（非 contextMenuActions）

| 标签 | 行为 |
|---|---|
| 在桌面散步 | 现有 roaming 开关 |
| 跪爬模式 | `crawlMode`；有 `crawl` 动画才显示 |

### 启动问候

`startupGreeting`：我们是闺蜜桌宠～今天也要一起玩。

## 质量门禁

- 切帧前通过源单元格安全边距、串帧、断尾/连通块检查；失败则重生成，禁止只擦碎片继续
- 全动作统一画布、视觉体量与脚底基线；互动连续重播 50 次无缩放/平移；静止点击不拖窗
- 透明像素鼠标穿透
- 双人同框时左右身份与相对站位稳定；贴纸脸不得进入成帧
- 验证 `.petpack` 后 `build:customer`，实际启动 EXE 检查：日常、合影变装、去放松不停顿续播、投喂臭粑粑、叫爸、下跪、跪爬模式+散步、拖拽、托盘、退出、独立数据目录

## 首版不做

- 覆盖或改名现有 `xiaomei-xiaotian` 客户包
- 双窗口独立漫游
- 为角色单独起名分气泡说话人
- 去放松中途点击选男模分支结局
- 数字签名与商店发布

## 建议实现顺序

1. 播放器：接入通用跪爬模式；如需则放宽 `contextMenuActions` 上限到 12
2. 建立 `guimi` 工作区与参考图清单，生成日常五动作 + crawl + call-dad + kowtow(±crawl)
3. 闺蜜彩蛋与合影变装序列
4. 投喂臭粑粑序列
5. 去放松分镜（无 waitForClick）
6. `petpack` 校验、`build:customer`、实机验收

## 风险

- 偏真人 + 双人 + 三套服装一致性成本高；必须固定站位与脸部锚点检查表
- 闺蜜一多张参考图脸被遮挡，只能以正脸自拍为脸部真相源
- 本分支缺跪爬模式时，需先合入通用播放器能力再交付，避免只在资源包里放 `crawl` 帧却无法切换模式
