# 老婆桌面宠物 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `feat/laopo-pet` 上将演示基线替换为「老婆」角色，交付 `laopo.petpack` 与「老婆桌面宠物」便携版 EXE。

**Architecture:** 宠物差异全部落在 `.petpack`（动画、`pet.json` 行为/菜单/女声音频）。播放器只做两处通用增强：可选 `startupGreeting`，以及 `behavior.random`/`perched` 可选 `speechAudio`。本分支移除 boss 演示位，改挂 `laopo`。

**Tech Stack:** Electron 播放器（`src/*-v3.js`）、`desktop-pet-maker` 绿幕条→去背→切帧流水线、Node 回归测试、`npm run build:customer`、可选 `edge-tts` 生成女声 mp3。

**Spec:** `docs/superpowers/specs/2026-08-01-laopo-pet-design.md`

## Global Constraints

- 分支：`feat/laopo-pet`（已存在，继续使用，不要另开）
- package id / delivery-id：`laopo`
- 程序名：`老婆桌面宠物`；宠物名：`老婆`
- `speechGender`: `female`；启动问候：`老公，我来啦~`
- 默认直立待机；`walk` 为直立散步；禁止爬行待机/移动
- `behavior.random` 禁止调度 `sleep`
- 不在播放器里按角色名写死菜单；不上传原图到无关服务
- 切帧失败必须重生成，禁止只擦串帧碎片继续
- **Git：** 用户规则优先——除非用户明确要求，否则跳过所有 `git commit` 步骤
- 每完成一个 Task，跑该 Task 列出的验证命令后再进入下一 Task

- [ ] **Step 3: 实现最小代码**

Create `src/startup-greeting.js`:

```js
'use strict';

function resolveStartupGreeting(manifest, { switching = false } = {}) {
  const custom = typeof manifest?.startupGreeting === 'string' ? manifest.startupGreeting.trim() : '';
  if (custom) return custom;
  const name = typeof manifest?.name === 'string' && manifest.name.trim() ? manifest.name.trim() : '桌宠';
  return switching ? `你好，我是${name}。` : `我是${name}。`;
}

module.exports = { resolveStartupGreeting };
```

在 `src/petpack-validator.js` 的 `validateManifest` 中、`speechGender` 校验后加入：

```js
if (manifest.startupGreeting !== undefined) {
  if (typeof manifest.startupGreeting !== 'string' || manifest.startupGreeting.length > 80) {
    throw new Error('startupGreeting 必须是不超过 80 个字符的字符串');
  }
}
```

在 `src/main-v3.js` 顶部 require，并替换两处：

```js
const { resolveStartupGreeting } = require('./startup-greeting');

// ready-to-show:

```

Python `petpack_tool.py` 的 `validate_manifest_shape` 增加同样长度校验；`petpack-schema.md` 增加字段说明。

```js
function setState(state, message = '', speech = '', logicalRole, speechAudio = '') {

  setState(state, message, speech, logicalRole, speechAudio || ''));
```
