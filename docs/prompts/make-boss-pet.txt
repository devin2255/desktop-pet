请根据我附上的西装中年男性参考照片，使用 desktop-pet-maker 在本仓库制作完整的 Windows 老板桌面宠物，并更新当前演示基线为该宠物。

宠物名字：牛斯克
性格：严肃、恭敬、粘人
程序名称：老板桌面宠物
delivery-id：boss
风格：柔和写实 2D 插画风，西装、白衬衫、黑皮鞋
重点特征：短棕发、浅胡茬、深色西装外套、跪姿为默认姿态
特殊要求：
1. 默认待机为跪姿；walk 使用爬行，不要直立走路。
2. sleep 可复用跪姿休息帧，但 behavior.random 禁止调度 sleep。
3. 右键菜单至少包含：
   - 叫大爷：气泡「大爷!」，男声「大爷」
   - 磕头：气泡「给您磕头了」
   - 错了没?：跪姿扇耳光，气泡与男声「我真该死」
4. 桌面漫游时，爬行间隙要随机插入端茶送水，气泡「大爷喝茶!」，频率不要太低。
5. 支持窗口互动：拖到上边框坐下、侧边攀爬、下边框吊挂、无窗时从屏顶坠落并拍屁股恢复。
6. 坐在上边框时，屁股要贴紧边框；坐边随机动作保留：
   - 跷二郎腿 + 脱鞋打电话（合成一套），气泡「喂, 军儿吗?」
   - 左看右看
   不要再做晃腿、抠鼻屎。
7. speechGender 设为 male；「大爷」「我真该死」优先使用内置男声音频，不要默认女声系统 TTS。
8. 启动问候显示「我是牛斯克。」

请保持所有动画帧是同一只角色，完成 idle/walk/sit/sleep/reaction 以及窗口互动、右键、坐边、端茶等动作；处理透明背景并统一画布、比例、重心和脚底基线。切帧前必须检查单元格安全边距、相邻帧串帧、完整肢体以及互动帧的尺度/重心漂移；任何一项失败都应重新生成，不能只擦除越界碎片。

生成并验证 pets/packages/boss.petpack 后，执行：

npm run build:boss

或：

npm run build:customer -- --pet pets/packages/boss.petpack --name "老板桌面宠物" --delivery-id boss

客户双击 EXE 后宠物必须直接出现，不需要安装开发环境，也不需要手动导入资源包。请实际启动成品，验证动画、透明背景及透明像素鼠标穿透、静止连续点击 50 次无放大/平移、拖动、漫游、左右朝向、右键菜单、坐边动作、托盘、退出和独立数据目录。最终把专属 EXE、build-report.json 和验证结果交付给我，不要只交付 .petpack。
