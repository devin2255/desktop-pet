## 结论

**大面积存在抠图侵蚀与肢体畸变，不只是跪爬。**  
根因倾向：生成条质量不稳 + Task5 去背 `edge-contract` + 全包 alpha 均衡压到 ~19.6k，动态姿势（手脚外展）被「啃边」。

## 分级

### P0 — 严重穿模 / 断肢（建议整动作重做）

| 动作 | 现象 |
| --- | --- |
| `fall` 全套 | 手脚被啃成细条，脚/手指缺失，面部缺口 |
| `drag` 多数帧 | 手臂拉丝、脚缺失、帽沿硬切 |
| `walk` 多数帧 | 手臂过细、脚后跟被切、帽顶平切 |
| `hang` | 举臂被吃边、腿细、头顶碎渣 |
| `climb` | 手臂畸变拉丝、脚被斜切 |
| `impact` / `recover` 部分帧 | 次级碎片 + 肢体变细 |

## 机器审计摘要

- 68 帧中 **44** 帧有 ≥20px 级碎片（多为帽翅/道具断开）
- **未发现** 像旧跪爬那种「脚整块飞到画布外」的大面积分离（跪爬断脚已修）
- 填充率最低（肢体被啃最狠）多为：`drag`、`walk`、`fall`、`hang`、`climb`

## 建议修复顺序

1. **整动作重生绿幕条**（逐帧生成，禁止一条克隆）：`fall` → `drag` → `walk` → `hang` → `climb` → `impact/recover`
2. 去背改用更温和参数：`edge-contract 0~1`，必要时 `edge-feather 1`；**取消**跨动作强行压到同一低 alpha 面积
3. 切帧：**禁止**为过门禁而整体缩小导致贴边裁肢
4. 复跑本审计脚本 + 目视抽查后再打包 EXE
